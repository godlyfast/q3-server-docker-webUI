Quick Start — All-in-One Bundle Complete Q3 experience: game data + CPMA + CPM maps + 4K textures + HD weapons + models + sounds (~6.3 GB)

Everything you need in a single download. Extract the baseq3/ and cpma/ folders into your ioquake3 directory. Grab the engine for your platform below.

IMPORTANT — Memory flags required!

The bundle includes 157+ pk3 files. You must launch with extra memory flags or the game will crash on startup (Z_Malloc error). These cannot be set in config files — they must be on the command line:

ioquake3 +set com_hunkMegs 1024 +set com_zoneMegs 512

See platform-specific instructions below for exact commands. The included autoexec.cfg handles all other settings.

Download pak0.pk3
Windows x86_64
  1. Download ioquake3 for Windows (~2.5 MB)
  2. Extract the zip anywhere (e.g. C:\ioquake3)
  3. Copy pak0.pk3 into the baseq3\ folder
  4. Create a shortcut to ioquake3.exe and add to Target:
    ioquake3.exe +set com_hunkMegs 1024 +set com_zoneMegs 512
    Or run from Command Prompt in the ioquake3 folder.

macOS Universal Binary
  1. Download ioquake3 for macOS (~40 MB)

    ~/Library/Application Support/Quake3/baseq3/
  4. Launch from Terminal:

Linux / Steam Deck x86_64
  1. Download ioquake3 for Linux

CPMA Mod Required when server is in CPMA mode

When the server runs CPMA (Challenge ProMode Arena), you need the CPMA pk3 to connect. Included in the all-in-one bundle above.

  1. Download CPMA 1.53 (16 MB)
  2. Place in a cpma/ folder next to your baseq3/ folder
  3. Add to your launch command:
    +set fs_game cpma +set com_hunkMegs 1024 +set com_zoneMegs 512

Source: playmorepromode.com
