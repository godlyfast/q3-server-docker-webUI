Game Data pak0.pk3 — required for all platforms

The base game data file needed by every platform. Download this first, then grab the engine for your OS below.

  1. Download pak0.pk3 (~500 MB)
  2. Copy it into the engine's baseq3/ folder (see platform instructions)
  3. Launch the game and connect:

/connect 192.168.55.100:27960

Download pak0.pk3
Windows x86_64
  1. Download ioquake3 for Windows (~2.5 MB)
  2. Extract the zip anywhere (e.g. C:\ioquake3)
  3. Copy pak0.pk3 into the baseq3\ folder
  4. Run ioquake3.exe

Open the console (~) and type:

/connect 192.168.55.100:27960

Download ioquake3
macOS Universal Binary
  1. Download ioquake3 for macOS (~40 MB)
  2. Extract and move ioquake3.app to Applications
  3. Copy pak0.pk3 to:
    ~/Library/Application Support/Quake3/baseq3/
  4. Launch ioquake3.app

Open the console (~) and type:

/connect 192.168.55.100:27960

Download ioquake3
Linux / Steam Deck x86_64
  1. Download ioquake3 for Linux
  2. Extract and chmod +x ioquake3.x86_64
  3. Copy pak0.pk3 to ~/.q3a/baseq3/
  4. Run ./ioquake3.x86_64

Steam Deck: Switch to Desktop mode, then follow the steps above. Add ioquake3 as a non-Steam game to launch from Gaming mode.

/connect 192.168.55.100:27960

OSP Mod Optional — competitive mod

OSP (Orange Smoothie Productions) adds competitive match features and Challenge Pro Mode (CPM) for faster gameplay. Only needed if connecting to a server running the OSP mod.

  1. Download OSP 1.03a (54 MB)
  2. Extract the osp/ folder next to your baseq3/ folder

HD Textures Optional — 4x upscaled textures

AI-upscaled texture packs that dramatically improve visual quality. Drop them into your baseq3/ folder alongside pak0.pk3 — no config needed.

  • Q3Q HD Upscale 4x (~982 MB)
  • wtf-q3a v3 (~136 MB)

These are client-side only. The server runs sv_pure 0 so any texture pk3s are allowed.
