Connection & Essential Setup How to connect and required launch flags

Connect (LAN):

/connect 192.168.55.100:27960

Connect (WAN):

/connect dczp.jsninjas.net:27960

Required memory flags — must be on the command line, not in config files:

ioquake3 +set com_hunkMegs 1024 +set com_zoneMegs 512

The server has 157+ pk3 files. Without these flags, the engine runs out of zone memory and crashes with a Z_Malloc error on startup. com_hunkMegs controls the main memory pool and com_zoneMegs controls the dynamic allocation zone — both are initialized before config files are read, so they must be set on the command line.

Mod Notes What to expect in each game mode

E+ (Excessive Plus)
300HP regen, multi-jump, overpowered weapons. FreezeTag = freeze enemies, stand near frozen teammates to thaw them.

OSP (OmniBot Server Patch)
Tournament-focused mod. Uses 125fps capped cgame — the server provides zzz-uncap-fps.pk3 override automatically.

CPMA (Challenge ProMode Arena)
VQ3 (default) or CPM (air control, plasma climb). Clan Arena = round-based elimination, no self-damage, full stack.
E+ Commands Excessive Plus — FreezeTag & gameplay
/team red Join red team
/team blue Join blue team
/team auto Auto-assign team
/team s Spectate
/callvote map <name> Vote to change map
/callvote g_gametype <n> Vote gametype (0=FFA, 8=FreezeTag)
/callvote fraglimit <n> Vote frag limit
/callvote timelimit <n> Vote time limit

FreezeTag rules: Frag an enemy to freeze them in place. Stand near a frozen teammate to thaw them. Round ends when an entire team is frozen. All weapons are overpowered — 300HP regen, multi-jump, and air control.

OSP2-BE Client Features OSP2 Black Edition — client-side enhancement by scoqx

OSP2-BE is a client-only enhancement for OSP 1.03a. It adds visual features, damage plums, bright models, and a SuperHUD system. It is auto-downloaded from the server — no manual install needed.

OSP2-BE SuperHUD Customizable HUD configs — osp/hud/

OSP2-BE includes a SuperHUD system with fully customizable HUD layouts. HUD configs are .cfg files in your osp/hud/ directory.

Command / CVar Description
cg_shud 1 Enable SuperHUD (0 = classic OSP HUD)
ch_file hud/Elite.cfg Load a specific HUD preset
/reloadHUD Reload current HUD without restart

Included HUD presets:

Elite, California, ChikiPiki, RTG, cybra, czm, flexo, Gothic, humiq, Misha, nasty, Pasha, qwerty, scoqx, scoqx_widescreen, Spayce, zpg

Place custom .cfg files in your osp/hud/ directory. Use /reloadHUD to apply changes without restarting the game.

Admin RCON Reference Remote console commands — available through the web UI

RCON commands can be sent from the Home page of this web UI (no need to use the in-game console).

map <name> Change to a specific map
map_restart Restart the current map
g_gametype <n> Set gametype (see values below)

addbot <name> <skill> Add a bot (skill 1–5)

timelimit <n> Set time limit (minutes)

Gametype values: FFA=0, Duel=1, TDM=3, CTF=4, CA=5 (CPMA/OSP), FreezeTag=8 (E+)
